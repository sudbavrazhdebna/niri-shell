# CLAUDE.md

nshell — свой шелл для niri (бар, меню, OSD, уведомления, idle, обои, док). Пользователь не пишет
код и проверяет визуально: после каждого шага — скриншот, что сделано, на что посмотреть.

- [DESIGN.md](DESIGN.md) — проектный документ: что делаем, решения, порядок шагов. `[решить]` —
  вопросы к пользователю; без ответа берем вариант из документа и пишем об этом.
- Живое ТЗ на поведение и справочник по хитрым местам — форк `~/Projects/wayle`
  (`NEW-SHELL.md`, `ROADMAP.md`, `TODO.md`). Код оттуда не копируем, пишем заново.

Код: «голый» gtk-rs без relm4, все на главном цикле GTK, без tokio (если только его не требует
библиотека). Ничего не опрашиваем таймером — только события. `unwrap`/`expect` запрещены clippy.

Проверка: `scripts/dev-nested.sh` (niri окном, работает и из GNOME; лог `.dev/nshell.log`),
скриншот `scripts/dev-shot.sh <path>`, команды внутри `scripts/dev-run.sh <cmd>`,
замер `scripts/dev-measure.sh 60`. Один шаг — один коммит.
